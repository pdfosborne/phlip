cloudflared (Cloudflare Tunnel) — third-party component bundled with Phlip
==========================================================================

Phlip bundles the cloudflared binary (the Cloudflare Tunnel client) to provide
optional "Public" hosting through a Cloudflare Tunnel.

It ships inside the APK's native library directory as:

    lib/arm64-v8a/libcloudflared.so

This is an UNMODIFIED upstream build of cloudflared. The only change Phlip makes
is the file NAME: it is renamed to "libcloudflared.so" so that Android extracts
it and permits it to be executed via ProcessBuilder on modern Android versions.
No changes are made to the cloudflared source or program behaviour.
